Sandi’s work

Rich Media Gallery：

PMP 團隊在過去3年間累積了大量的 Rich Media 案例。為了降低提案時與客戶溝通的高成本加速雙方的達成共識，我開發了 Gallery 網站，將過往專案系統化建立標籤系統（Tagging System），讓業務與客戶能直觀地選定廣告版型。
在 Rich Media Media 中結構為雙軌式導覽，分別為 Template、我們把廣告樣式做成 Template(廣告樣式庫)、Showcase(精選案例)。

廣告樣式庫 (Template)：
將廣告結構模組化，客戶可依據行銷需求（如：互動率、點擊導向）選擇對應的版型。
精選案例 (Showcase)：
依產業類別分類，提供實戰案例參考，協助客戶快速找到與品牌屬性相符的創意靈感。

Rich Media Gallery 介面

技術實踐
此 Gallery 完整保留了 Rich Media 的動態特性，使用者點選後可即時預覽廣告互動效果並查看詳細規格。在專案維護上，考量到團隊維護的便利性，使用 Google Sheets API 打造簡易 CMS，實現全員自動化維護；前端即時渲染廣告互動效果，讓團隊成員無須接觸程式碼，只要擁有 Google sheet 編輯權限即可隨時新增、管理廣告專案。

In-stream Video：

在團隊中另一個服務是針對國內知名 OTT/CTV 影音市場的廣告投放，Gallery 同步整合了 VPAID (可互動影音) 與 VAST (純影音) 格式，並透過標籤系統讓使用者能根據投放需求快速篩選。
