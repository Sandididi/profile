Sandi’s work

Rich Media Gallery：
PMP 團隊在過去3年間累積大量的 Rich Media 案例，為了在提案與客戶溝通時能更快速的達成共識，我們將專案分類整理成 Gallery Web。
在 Rich Media Media 中主要分兩大主頁，我們把廣告樣式做成 Template 客戶可以依據廣告的需求特性選擇喜歡的模板；另一頁是 show case 客戶可以參考近期不同產業的其他客戶選擇的樣式，並從中找到屬意的廣告樣式。

為了保留 Rich Media Gallery 可互動的特性，以及讓全體團隊成員皆能新增與管理最新廣告專案，我們使用 Google sheet API 當作我們的簡易後台，使用者點選廣告模板後會彈出該廣告樣式的說明，並且及時地叫出廣告互動。

In-stream Video：
PMP 也能選擇投放影音廣告在主流的 OTT/CTV 平台，主要投放的格式分為可互動 VPAID 格式、純影音 VAST 格式，在 Gallery 中也可以透過標籤找到相對應的廣告格式。
